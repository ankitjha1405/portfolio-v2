Install · 5 minutes

Set it up once

You need Claude Code, Python 3 and ffmpeg. Commands below are for macOS. On Linux, use sudo apt install ffmpeg instead of brew.

  1. Install the free tools 
    brew install ffmpeg
pip3 install pillow edge-tts
  2. Add the skill to Claude Code 
    curl -L https://reelforge.ankitjha1405.tech/reelforge/faceless-reels.zip -o faceless-reels.zip
unzip faceless-reels.zip -d ~/.claude/skills/

    Or download the zip above and unzip it into ~/.claude/skills/.

  3. Open Claude Code in any folder and ask 
    make a faceless reel about why cats knock things off tables

    Claude shows its plan and 3 scripts. You pick one. Your mp4 lands in ./reels/.

Grow with it

How to get value from it

Posting playbook

  • Pick one niche and one format. Repeat the same look so people know your page on sight.
  • Use series for return viewers. A cliffhanger gives people a reason to follow for part 2.
  • Batch on one day. Make a week of reels in one sitting, then schedule them.
  • Judge the hook. Choose the script whose first line you would stop scrolling for.
  • Use the caption file. Each video comes with a .txt holding a caption and hashtags.

Who it's for

  • Creators who want to post daily without being on camera.
  • Educators turning lessons into 30-second explainers.
  • Founders and marketers testing content angles before spending on editors.

Good to know

FAQ

Is it really free?

Yes. Images come from Pollinations and the voice from Microsoft Edge TTS, both free. The scripts are written by Claude inside your own Claude Code plan.

Why does rendering take a few minutes?

Free Pollinations images are limited to 1 every 45 seconds, and small images carry their watermark. A free key from enter.pollinations.ai, set as POLLINATIONS_KEY, removes both limits.

Can I post these on Instagram and YouTube?

Yes. Platforms ask you to label realistic AI-generated content, so turn on the AI label when you upload. Avoid real people's likeness and brand characters in your ideas.

Can I change a scene I don't like?

Yes. Ask Claude to redo that scene. It edits plan.json and renders again.

Does it work on Windows?

Yes, if Python and ffmpeg are installed and on your PATH. Unzip the skill into %USERPROFILE%\.claude\skills\.
