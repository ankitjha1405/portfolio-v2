Tell Claude your idea. It picks the format and art style, writes 3 scripts for you to choose from, then makes the video with AI images, voiceover and captions. Ready to post on Reels, Shorts and TikTok.

Download the skill
  • No API key
  • 10 video formats
  • Single reel or series

Set it up in 3 steps

  1. Install the free tools

    macOS shown. On Linux use apt for ffmpeg.

    brew install ffmpeg
pip3 install pillow edge-tts
  2. Add the skill

    Unzip the download into your skills folder.

    unzip faceless-reels.zip \
  -d ~/.claude/skills/
  3. Ask for a reel

    In Claude Code, any folder.

    make a faceless reel
about how rain forms

Your video and a ready caption with hashtags land in ./reels/. Free images are limited to one every 45 seconds, so a 30-second reel takes a few minutes. Turn on the AI label when you upload.
